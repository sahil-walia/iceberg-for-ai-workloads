## Experiments and Paper Mapping

| Script | Experiment | Paper Location | Key Result |
|--------|-----------|---------------|------------|
| `01_compaction_local.py` | Local compaction — 200 commits (Spark 3.5.9) | Section VI, Table IV | 2.38× speedup, 200→1 files |
| `01_compaction_local.py` | Local compaction — 1,000 commits (Spark 3.5.9) | Section VI, Table IV | 2.60× speedup, 1,000→1 files |
| `02_compaction_s3.py` | Compaction on Amazon S3 (Spark 4.0.1) | Section VI, Table IV | 6.52× speedup over WAN |

## Environment

All experiments ran on:

- **Hardware:** Apple Silicon arm64, 14 logical CPUs, 36 GiB RAM
- **OS:** macOS (arm64)
- **Java:** 17 (required for Iceberg 1.11.0)
- **Python:** 3.11.6 (Spark 3.5.9 trials), 3.14.2 (S3 and Spark 4.0.1 trials); 3.9+ sufficient for reproduction
- **Iceberg:** 1.11.0 (loaded via `spark.jars.packages` at runtime)
- **Spark:** 3.5.9 (primary trials) and 4.0.1 (S3 and version-consistency trials)

For `02_compaction_s3.py`: AWS credentials must be configured via the standard
`~/.aws/credentials` file or environment variables. The script uses bucket
`swalia-iceberg-benchmark` in `us-west-2`; update the bucket name before running.

## Reproducing the Experiments

```bash
# Install Python dependencies
pip install pyspark==3.5.9 matplotlib

# Local compaction — 200 commits (matches paper's primary trial)
python experiments/01_compaction_local.py --batches 200 --rows-per-batch 5000 --repetitions 7 --measure-every 25

# Local compaction — 1,000 commits
python experiments/01_compaction_local.py --batches 1000 --rows-per-batch 5000 --repetitions 7 --measure-every 100

# WAP overhead
python experiments/03_wap_overhead.py

# Spark 4.0.1 version consistency (install pyspark==4.0.1 first)
python experiments/04_compaction_spark4.py --batches 200 --rows-per-batch 5000 --repetitions 7 --measure-every 25

# S3 trial (install pyspark==4.0.1 first; requires AWS credentials and bucket)
python experiments/02_compaction_s3.py --batches 200 --rows-per-batch 5000

# Regenerate Figure 1 from stored results
python figures/gen_paired_bars.py
```

Each script writes a timestamped JSON and CSV to `results/` by default.
The JSON files include environment metadata, Iceberg procedure output,
per-trial timing (median, min, max, stdev over 7 scans), and row/checksum
verification.

## Scope and Limitations

The local experiments use compressed datasets of approximately 4.5–22 MB on a
single local filesystem with no concurrent writers. They demonstrate the
direction and local magnitude of the small-file maintenance effect; they do not
reproduce the 71× speedup cited from the AWS SageMaker Feature Store deployment
(106.5 GiB, 49.9 M S3 objects, production-scale concurrency).

The S3 trial uses a single local host writing to S3 over a broadband WAN
connection. It is not representative of colocated cloud compute.
